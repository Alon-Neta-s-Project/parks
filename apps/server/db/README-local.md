# Running the migrations locally

```sh
apt-get install -y postgresql-16 postgresql-16-pgvector

export PGDATA=/tmp/pgdata PGPORT=55432
rm -rf $PGDATA && mkdir -p $PGDATA && chown postgres:postgres $PGDATA /tmp
# ⚠️ **en_US.UTF-8, not C.** The Supabase locale is en_US.UTF-8, and the difference
# is not cosmetic: pg_trgm decides "what is an alphanumeric character" by LC_CTYPE, and
# under the C locale a Hebrew letter does not count as a letter — every trigram
# similarity returns 0.00, even on an exact match. That is, the fuzzy layer works
# in production and dies silently locally.
localedef -i en_US -f UTF-8 en_US.UTF-8
su postgres -c "/usr/lib/postgresql/16/bin/initdb -D $PGDATA -A trust --locale=en_US.UTF-8 --encoding=UTF8"
su postgres -c "/usr/lib/postgresql/16/bin/pg_ctl -D $PGDATA -o '-p $PGPORT -k /tmp' -l /tmp/pg.log start -w"
su postgres -c "psql -h /tmp -p $PGPORT -d postgres -c 'create database pdc;'"

# ⚠️ First the local layer, then the chain in order
for f in apps/server/db/local/000_auth_shim apps/server/db/migrations/0*_* apps/server/db/seed/0*_*; do
  su postgres -c "psql -h /tmp -p $PGPORT -d pdc -v ON_ERROR_STOP=1 -q -f $f"
done
```

## Why `apps/server/db/local/000_auth_shim.sql` is needed

Migration 004 references `auth.users`, and 006 calls `auth.uid()`. **The `auth` schema belongs
to Supabase and does not exist in a clean PostgreSQL**, so without it the chain stops at 004.
In production on Supabase the schema exists, and this file must not be run.

**Verified result:** the 22 files run clean, creating **19 tables**, 4 views
and 29 RLS policies.

> This README previously said "21 tables". 21 is tables **plus** views
> (18 + 3). The correct count is 18. `apps/server/db/verify.sql` checks the two separately.

## Verification

```sh
psql -h /tmp -p $PGPORT -d pdc -f apps/server/db/verify.sql      # what was actually created
psql -h /tmp -p $PGPORT -d pdc -f apps/server/db/local/rls-audit.sql
```

## The file for Supabase

`apps/server/db/supabase-bundle.sql` — everything in one file, without the local scaffolding, with a verification block
at the end. Generated by `python3 scripts/build-supabase-bundle.py` and must not be edited by hand.
