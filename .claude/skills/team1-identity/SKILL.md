# זהות בכל פלט/תגובה — צוות 1

**מקור-אמת יחיד.** הבלוק הזה הופיע חמש פעמים בקובץ שפולה שלחה (18.09) — פעם
בכל סקיל. חמישה עותקים הם חמישה מקורות-אמת, וזה בדיוק מה ש-`CLAUDE.md` אוסר
("תוכן שמופיע בשני מסכים נוצר, ולא מודבק פעמיים"). הוא נכתב כאן פעם אחת, וכל
סוכן מפנה לכאן.

## הכלל

כל תגובה שסוכן של צוות 1 כותב במקום ציבורי-משותף — GitHub Issue, תגובת
commit, כל פלט-כתוב שיוצא ממנו לעורץ שאינו הדיווח-הפנימי-לפולה-החדשה —
**נפתחת בשם-הסוכן, בשורה נפרדת משלה**:

```
[<שם-הסוכן>]
<תוכן התגובה עצמה>
```

## המחבר ב-commit

```sh
git -c user.name="<שם-הסוכן>" commit -m "..."
```

⚠️ **ולא `git config user.name`.** `git config` כותב ל-`.git/config` — מצב
משותף לכל מי שעובד בעץ-העבודה הזה. שני סוכנים שרצים במקביל דורסים זה את זה,
והשני מקבל את השם של הראשון בשקט. `git -c` חל על הפקודה הזו בלבד ואינו יכול
להידרס. (תיקון של קודי לנוסח 18.09; ראו ההודעה לפולה מאותו יום.)

## שמות הסוכנים

| סוכן | שם בעברית (לפלט ול-commit) | שם ASCII (frontmatter) |
|---|---|---|
| האיסוף | `סוכן-האיסוף` | `team1-scraper` |
| השוער | `שוער-התוכן` | `team1-gatekeeper` |
| המסדר | `המסדר` | `team1-organizer` |
| המוודא | `המוודא` | `team1-verifier` |
| המנג'ר | `פולה-החדשה` | `team1-manager` |

**השם בעברית הוא מה שבני-אדם רואים. שם ה-ASCII הוא מה ש-Claude Code טוען.**
שדה `name` בראש קובץ סוכן מוגבל לאותיות-קטנות-לועזיות ולמקפים — שם עברי שם
פשוט לא נטען, בלי שגיאה שמישהו רואה.

## הסיבה (קודי, 18.09)

כל הסשנים רצים תחת חשבון-הגיטהאב האישי של נטע — בלי שם-נפרד, ההיסטוריה כולה
נראית כאילו נטע כתבה אותה, ואי-אפשר לשחזר בדיעבד מי מחמשת הסוכנים כתב מה.
