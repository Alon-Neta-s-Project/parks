# Park Day Companion

מדריך תוכן בעברית לפארקים באורלנדו, וטים — צ'אטבוט שנשען על אותו מסד נתונים.
הבריף המלא: [`docs/master-brief-v1.md`](docs/master-brief-v1.md).

## מצב ה-repo — קרא לפני שממשיכים

ה-repo היה **ריק לגמרי** בתחילת העבודה. שני דברים שהבריף מניח שקיימים, אינם כאן:

- **`db/`** — שש המיגרציות ו-seed (סעיף 6). בלעדיהן אין סכמה, ולכן אין
  `content-mapping.json` ואין `scripts/import-content.ts`. סעיף 1.3 אוסר להמציא מבנה נתונים.
- **11 מסמכי הרקע** של סעיף 2 — כולל `tim-retrieval-and-memory-architecture.md`,
  שהבריף מסמן כקריטי ביותר לחלק ב'.

לכן M0 לא התחיל. מה שכן אפשר היה לעשות בלי להמציא — נעשה, והוא כאן.

## מה יש

| נתיב | מה זה |
|---|---|
| `data/source/` | הקובץ שנטע העבירה, כלשונו, ועותק JSON של כל גיליון |
| `docs/content-file-analysis.md` | **דוח הכיסוי בשני הכיוונים** (סעיף 6א.3) — מה הבריף דורש שאין בקובץ, ומה בקובץ שאין לו בית בסכמה |
| `docs/master-brief-v1.md` | הבריף כפי שהתקבל |
| `design/tokens.css` | **מקור האמת היחיד לצבע וטיפוגרפיה** (סעיף 4.2). הקובץ היחיד ב-repo שמכיל ערכי צבע |
| `design/preview/page.html` | דף האישור של M1 — טוקנים, אייקונים, שלושה מסכים |
| `design/preview/index.html` | נבנה מהשניים שמעל. **לא לערוך ידנית** |
| `scripts/export-source-xlsx.py` | ייצוא הגיליונות ל-JSON. לא הייבוא של סעיף 6א |
| `scripts/build-preview.py` | הזרקת `tokens.css` לתוך דף התצוגה |

```sh
python3 -m pip install openpyxl
python3 scripts/export-source-xlsx.py   # xlsx -> data/source/*.json
python3 scripts/build-preview.py        # tokens.css + page.html -> index.html
```

## מה חסום ולמה

הפירוט המלא בסוף `docs/content-file-analysis.md`. בקצרה:

1. **`db/` ומסמכי הרקע לא ב-repo** — החוסם הראשון.
2. **רגישויות ומגבלות גובה: 0 מתוך 477 שורות.** שני אלה הם הפיצ'ר המבחין של גרסה 1
   (סעיף 3.2) ושדות חובה בשלושה ממקרי ה-eval (סעיף 11). אין להם מקור בקובץ הנוכחי.
3. **תוכן עריכתי וסרטונים: 0 מתוך 477.** לפי סעיף 3.3א, אף דף מתקן אינו "מוכן" כרגע.
4. **אינטנסיביות: 107 מתוך 232.** אפס כיסוי ב-Epic Universe ובשלושת פארקי המים.

## כללי עבודה שנשמרים בקוד

- **אין תוכן מומצא.** כל ערך בדף התצוגה נלקח משורה אמיתית בקובץ. שדה בלי מקור מוצג כ"אין נתון".
- **אין ערכי צבע קשיחים** מחוץ ל-`design/tokens.css`.
- **RTL לוגי בלבד** — `inline-start`/`inline-end`/`block-*`. אין `left`/`right`/`margin-left`.
- **שם אנגלי בתוך משפט עברי** מבודד תמיד (`<bdi>` או `unicode-bidi: isolate`).
