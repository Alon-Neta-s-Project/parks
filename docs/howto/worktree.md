# עבודה עם worktree — שני ענפים באותו זמן

## הבעיה שזה פותר

היום יש תיקייה אחת וענף אחד. מעבר בין ענף העבודה ל-`release` דורש
`git checkout`, וזה **משנה את הקבצים תחת הרגליים** — כולל תוצרי בנייה
ו-`node_modules` שלא תמיד תואמים.

⚠️ **וזה נעשה מסוכן ברגע שיש כמה סוכנים.** שניים שעובדים באותה תיקייה
על ענפים שונים דורסים זה את זה בלי להתריע.

## איך

```sh
# פעם אחת — release כתיקייה נפרדת, לצד הראשית
git worktree add ../park-planner-release release

# מכאן והלאה: שתי התיקיות חיות במקביל, כל אחת על הענף שלה
cd ../park-planner-release && git pull    # מעדכן את release בלבד
```

⚠️ **`node_modules` אינו משותף.** בתיקייה החדשה צריך `npm install` משלה.
זה המחיר, והוא חד־פעמי.

## מה זה **לא** פותר

זה אינו מחליף את שער ה-QA. worktree מאפשר לעבוד על שני ענפים; הוא אינו
מוודא שמה שנדחף תקין. `npm run qa` הוא זה.

## ניקוי

```sh
git worktree list              # מה קיים
git worktree remove ../park-planner-release
```

⚠️ **תיקייה שנמחקה ביד משאירה רישום יתום.** `git worktree prune` מנקה.
